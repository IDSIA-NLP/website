# NLP Group at IDSIA – website

Source of **https://nlp.idsia.ch**. All content is plain text (Markdown and BibTeX);
the design is applied automatically.

## How to make a change

1. Open the file on github.com, click the pencil icon, edit, and choose
   **"Create a new branch and start a pull request"**.
2. After about a minute, a **preview link** appears on the pull request. Check your change there.
3. Once approved, it goes live within a few minutes.

## What do you want to do?

| Task                         | Edit                                              |
|------------------------------|---------------------------------------------------|
| Update your profile          | `content/people/<your-name>/index.md`             |
| Add a publication            | `publications.bib`                                |
| Add a news item              | new file in `content/news/`                       |
| Add or update a project      | `content/projects/<name>.md`                      |
| Add code, data or a tool     | `content/resources/<name>.md`                     |
